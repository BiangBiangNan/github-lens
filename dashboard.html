你的开源探索空间

GitHub Lens 1.0 · 无账号、无追踪、无远程脚本。

数据与权限

仅访问 GitHub API 和 GitHub Trending。收藏、保存的搜索及主题保存在当前 Chrome 配置中，不会同步或上传。扩展不会读取浏览记录，也不会修改 GitHub 页面。

免费接口的边界

未登录 GitHub 搜索接口通常限制每分钟约 10 次，并受 API 总额度、共享网络和 GitHub 动态限制影响。结果缓存 5 分钟，最多浏览前 990 条（33 页），GitHub API 自身上限为前 1,000 条。遇到限流请按提示稍后重试。

两种「热门」

热门趋势直接读取 GitHub Trending 榜单；近期高星是最近 30 天创建、至少 100 Star 的仓库按总 Star 排序，不等同于涨星榜。Trending 页面结构变化可能导致解析失败，会明确提示，不会用伪榜单替代。
